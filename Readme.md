# SkyIndia Flight Simulator

A browser-based 3D flight simulator.

## Features

- Airbus aircraft selection
- Concorde selection
- Airline liveries
- Indian airport selection
- VNS Varanasi featured airport
- Three.js 3D graphics
- Runway and terminal scenery
- Flight HUD
- Keyboard controls

## Installation

Install Node.js.

Run:

npm install

Start:

npm run dev

Build:

npm run build

## Render Deployment

Build command:

npm install && npm run build

Publish directory:

dist

## Controls

W - Pitch up
S - Pitch down
A - Bank left
D - Bank right
Q - Yaw left
E - Yaw right
SHIFT - Throttle up
CTRL - Throttle down
G - Landing gear
F - Flaps
B - Brakes
R - Reset

## Disclaimer

This is an educational simulator prototype.
It is not intended for real-world aviation training.
